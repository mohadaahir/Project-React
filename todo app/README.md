# Daybook

A small, calm todo list for keeping track of what needs your attention today. Tasks are saved in your browser, so they stay available after a refresh.

## Run locally

```sh
npm install
npm run dev
```

## Available commands

- `npm run dev` starts the local development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` checks the source files with ESLint.

## Features

- Add, complete, and delete tasks.
- Filter the list by all, active, or completed tasks.
- Clear all completed tasks at once.
- Persist tasks in browser local storage.
- Responsive layout with keyboard focus and reduced-motion support.
